# Mute Menu — Fabric 1.21.11

Клиентский мод: кликабельные имена игроков в чате становятся бирюзовыми и подчёркнутыми. Нажатие открывает меню правил 3.1–3.10. При выборе правила клиент отправляет серверу `/tempmute <ник> <время> <правило>`.

## Правила и команды
- 3.1 — `1h`
- 3.2 — `30m`
- 3.3 — `3d`
- 3.4 — `1h`
- 3.5 — `14d`
- 3.6 — `1d`
- 3.7 — `1d`
- 3.8 — `7d`
- 3.9 — `7d`
- 3.10 — `1h`

## Сборка
Требуется Java 21. В папке проекта запустите `./gradlew build` (Windows: `gradlew.bat build`). JAR будет в `build/libs/`.

## Установка
Положите `mute-menu-1.0.0.jar` в папку `.minecraft/mods`. Нужны Fabric Loader для Minecraft 1.21.11 и Fabric API 1.21.11. Мод клиентский — на сервер ставить его не нужно.

Важно: на сервере должна работать команда `/tempmute`, а у вашего аккаунта должны быть права на её выполнение. Длительности указаны в формате, который вы привели (`m`, `h`, `d`).
